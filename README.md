# To-Do List

A simple and interactive To-Do List application that helps users manage daily tasks efficiently through an intuitive and responsive interface.

## Project Overview

This project allows users to add, complete, and delete tasks, making it easier to organize daily activities and improve productivity. The application provides a clean design and smooth user experience for effective task management.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Real-time task updates
* Responsive user interface
* Simple and easy-to-use design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Workflow

1. Enter a task
2. Add the task to the list
3. Mark tasks as completed when finished
4. Remove completed or unwanted tasks
5. Manage daily activities efficiently

## Installation

Clone the repository:

```bash
git clone https://github.com/akshaya2408/To-Do-List.git
```

Navigate to the project directory:

```bash
cd To-Do-List
```

## Run the Project

Open the project in your browser:

```text
index.html
```

Or run using VS Code Live Server:

```text
Right Click → Open with Live Server
```
